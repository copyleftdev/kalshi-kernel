# Support

Kalshi Kernel is community-maintained pre-release software. It has no service
level agreement and is not supported by Kalshi, OpenAI, Anthropic, or the Model
Context Protocol maintainers.

Use the repository's issue tracker for reproducible bugs, documentation
problems, and feature proposals. Before filing:

1. Confirm the issue occurs on the latest default branch.
2. Run `make public-check` and include the relevant non-sensitive output.
3. State the operating system, architecture, Go version, MCP client, execution
   mode, and server version.
4. Provide a minimal reproduction with credentials and account data removed.

Do not request trading advice, market predictions, legal interpretations, or
help evading exchange, platform, or jurisdictional restrictions.

For security issues, credential exposure, or behavior that could submit an
unintended order, follow [SECURITY.md](SECURITY.md) and report privately.
