# Kernel visual identity

This is an independent identity for the open-source Kernel project. It is not
the Kalshi logo, an official Kalshi sub-brand lockup, or evidence of endorsement
or affiliation.

The mark is an original geometric `K`. Its green center represents the small,
trusted core that sits between an agent and a broad trading API. The vector
wordmark is built from paths and does not use or redistribute Kalshi Sans.

## Assets

| Surface | Lockup | Mark |
| --- | --- | --- |
| White or `#F5F7F4` | `kernel-lockup-light.svg` | `kernel-mark-light.svg` |
| `#050D0A` | `kernel-lockup-dark.svg` | `kernel-mark-dark.svg` |

The light artwork uses `#050D0A` and Kalshi's light-mode green, `#00B67A`. The
dark artwork uses `#FFFFFF` and Kalshi's dark-mode green, `#00DD94`. Do not swap
the two greens between light and dark surfaces. Each SVG includes its approved
background so the pairing remains intact when embedded on another surface.

## Clear space and sizing

The mark's vertical stem is the unit `X`. Keep at least `2X` of empty space
around the complete mark or lockup. That clear space is already included in each
SVG view box. Do not crop it away.

Use the full lockup at 160 CSS pixels wide or larger. Below that size, use the
standalone mark at 24 CSS pixels or larger. Keep the original aspect ratio.

## Usage

- Use only the supplied light or dark artwork.
- Keep the artwork flat: no shadows, outlines, gradients, masks, or textures.
- Do not rotate, stretch, crop, rearrange, or recolor it.
- Do not combine it with the Kalshi wordmark or present it as a Kalshi sub-brand.
- Keep the project's unofficial/non-affiliation notice visible wherever the
  surrounding context could imply an official integration.
- Refer to the software as “Kernel” in the mark. Use “for Kalshi APIs” only as
  descriptive prose, not as part of the logo.

These rules apply Kalshi's published principles conservatively without claiming
that Kalshi has reviewed or approved this identity. Kalshi's current brand kit
and usage terms remain authoritative:
<https://kalshi.com/brandkit>. For an official determination, contact
`creative@kalshi.com`.
